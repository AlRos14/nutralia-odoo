# Nutralia ERP Modules Repository

## Overview

This repository contains a collection of custom Odoo 16 Community modules developed by Alejandro Rosado as a gift for my father (owner of Nutralia Foods S.L.). The modules are designed to enhance and customize the ERP system for specific business needs.

## Modules

The repository includes the following custom modules:

1. `lot_visibility_nutralia`
2. `odoo_price_control`
3. `product_standard_margin`
4. `sale_margin_nutralia`

Each module contains its own README file explaining its specific functionalities in detail.

## Compatibility

- **Odoo Version:** 16 Community Edition
